# دليل التشغيل والنشر الشامل لمدونتك الاحترافية

يسعدني أن نصل إلى هذه المرحلة الحاسمة. لقد قمنا بتصميم قاعدة البيانات، وبناء واجهة عرض المقالات، وإنشاء لوحة تحكم إدارية (Admin Dashboard) متكاملة تدعم تعدد اللغات (الإنجليزية، الفرنسية، الإسبانية) وتتيح حقن الإعلانات برمجياً.

## محتويات الملفات البرمجية الجاهزة في مجلد العمل:
1. `supabaseClient.js`: ملف الاتصال بقاعدة بيانات Supabase.
2. `dataService.js`: دوال جلب المقالات والترجمات والإعلانات.
3. `ArticlePage.jsx`: واجهة عرض المقال مع حقن الإعلانات تلقائياً.
4. `AdminDashboard.jsx`: لوحة تحكم لإضافة ونشر المقالات بسهولة.

---

## خطوة بخطوة للتشغيل والنشر:

### الخطوة الأولى: إنشاء مشروع Next.js جديد محلياً
افتح الطرفية (Terminal) على جهازك وقم بتشغيل الأوامر التالية لإنشاء مشروع Next.js جديد:
```bash
npx create-next-app@latest my-remote-blog
cd my-remote-blog
npm install @supabase/supabase-js
```

### الخطوة الثانية: إضافة الملفات البرمجية
قم بنسخ الملفات التي أنشأناها (الملفات الأربعة المذكورة أعلاه) إلى مجلد مشروعك الجديد في المكان المناسب (مثلاً داخل مجلد `components` ومجلد `services`).

### الخطوة الثالثة: ربط متغيرات البيئة (.env.local)
أنشئ ملفاً باسم `.env.local` في جذر مشروعك وأضف مفاتيح Supabase الخاصة بك:
```env
NEXT_PUBLIC_SUPABASE_URL=ضع_رابط_مشروعك_هنا
NEXT_PUBLIC_SUPABASE_ANON_KEY=ضع_مفتاح_الـ_anon_هنا
```

### الخطوة الرابعة: النشر المجاني على Vercel
1. ارفع مشروعك على مستودع GitHub خاص بك.
2. اذهب إلى [Vercel](https://vercel.com/) وقم بربط حسابك بـ GitHub.
3. اختر المستودع وأضف متغيرات البيئة (Environment Variables) نفسها التي وضعتها في `.env.local`.
4. اضغط Deploy، ومبارك عليك مدونتك السحابية المجالية والآمنة!
